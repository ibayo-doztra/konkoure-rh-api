Masquer l'UID du badge affiché dans le profil employé

## Constat

L'UID du badge NFC est actuellement affiché en clair dans la section « Informations personnelles » du profil employé (`src/routes/_authenticated.app.employees.$id.tsx`). L'utilisateur souhaite le masquer pour éviter la duplication : afficher les 2 premiers caractères et remplacer le reste par des astérisques, en nombre supérieur à la longueur réelle de l'UID.

## Correctifs

1. **Fonction utilitaire** — ajouter `maskBadgeUid(uid: string | null): string` dans `src/lib/utils.ts`.
   - Si `uid` est vide ou null, retourner « — ».
   - Sinon, retourner les 2 premiers caractères suivis d'une chaîne d'astérisques de longueur `uid.length + 4` (par exemple, un UID de 14 caractères donne `0C**************`).
   - Cohérent avec la règle mémoire : pas de classe Tailwind codée en dur, utilisation de tokens sémantiques déjà en place.
2. **Profil employé** — dans `src/routes/_authenticated.app.employees.$id.tsx`, ligne ~213, remplacer `value={badgeInfo.uid}` par `value={maskBadgeUid(badgeInfo.uid)}`.
3. **Champ d'édition admin** — ne pas masquer l'UID dans `src/components/employees/NfcBadgeCard.tsx` : cet input est réservé aux admins et doit permettre la saisie/lecture exacte pour attribution ou révocation.

## Détails techniques

- `src/lib/utils.ts` : ajout de la fonction de masquage.
- `src/routes/_authenticated.app.employees.$id.tsx` : affichage masqué via le composant `Field` existant.
- Aucun changement de logique métier, de base de données ni de droits d'accès.
