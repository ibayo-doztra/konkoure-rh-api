Rendre les commentaires de performance lisibles en mode lecture seule

## Contexte
Sur la page de détail d'une évaluation (`/app/performance/reviews/:id`), les commentaires de l'employé et du manager sont affichés dans des `<Textarea>` grisés lorsqu'ils sont en lecture seule. Cela rend la lecture difficile, notamment sur les longs textes avec retours à la ligne.

## Objectif
Afficher les commentaires en lecture seule sous forme de paragraphes simples avec conservation des retours à la ligne, au lieu de textarea désactivés.

## Modifications prévues
1. **Commentaires employé par objectif** : quand `!canEditSelf`, remplacer le `<Textarea disabled>` par un `<p>` avec `whitespace-pre-wrap` et couleur `text-foreground`.
2. **Commentaires manager par objectif** : quand le manager ne peut plus éditer (`!canEditManager || managerSubmitted`), remplacer le `<Textarea disabled>` par un `<p>` avec `whitespace-pre-wrap`.
3. **Auto-évaluation globale** : quand `!canEditSelf`, remplacer le `<Textarea disabled>` par un paragraphe avec conservation des retours à la ligne.
4. **Bilan manager global** : quand le manager est en lecture seule, remplacer le `<Textarea disabled>` par un paragraphe.
5. Conserver les `<Textarea>` éditables lorsque l'utilisateur a les droits d'édition.
6. Utiliser les tokens sémantiques Tailwind (`text-foreground`, `text-muted-foreground`) sans couleur codée en dur.

## Fichier concerné
- `src/routes/_authenticated.app.performance.reviews.$id.tsx`

## Validation
- Vérifier visuellement que les commentaires en lecture seule s'affichent comme du texte lisible avec retours à la ligne conservés.
- S'assurer que les champs restent éditables dans les phases autorisées.
